# 📚 Trilha Python — DIO

Bem-vindo(a) ao repositório da **Trilha Python da Digital Innovation One (DIO)**!

Aqui você encontrará códigos, desafios, exercícios e exemplos desenvolvidos ao longo da trilha — desde fundamentos até tópicos como Flask, Django e FastAPI.

---

## 🚀 Objetivo

Reunir os módulos da trilha, registrar resoluções e servir como material de apoio para estudos.

---

## 🧭 Estrutura do repositório

Cada pasta representa um módulo do curso e contém exemplos, scripts e resoluções.

Exemplo de estrutura:

```
trilha-python-dio/
├── 00 - Fundamentos/
├── 01 - Estrutura de dados/
├── 02 - Programação Orientada a Objetos/
├── 03 - Decoradores, Iteradores e Geradores/
├── 04 - Data e hora/
├── 05 - Manipulação de arquivos/
├── 06 - Gerenciamento de pacotes e boas práticas/
├── 07 - Banco de dados/
├── 11 - Desenvolvimento de APIs com Flask/
├── 12 - Desenvolvimento fullstack com Django/
└── 13 - APIs Assíncronas com FastAPI/
```

### Descrição (resumo) dos módulos

- 00 — Fundamentos: sintaxe básica, tipos, operadores e estruturas condicionais.
- 01 — Estruturas de dados: listas, tuplas, dicionários, conjuntos.
- 02 — POO: classes, herança, encapsulamento, polimorfismo.
- 03 — Decoradores, iteradores e geradores: recursos avançados.
- 04 — Data e hora: manipulação e formatação de datas.
- 05 — Manipulação de arquivos: leitura, escrita e tratamento de exceções.
- 06 — Gerenciamento de pacotes: `pip`, ambientes virtuais e boas práticas.
- 07 — Banco de dados: SQL e integração com Python.
- 11 — APIs com Flask: endpoints, rotas e validação.
- 12 — Django: backend, ORM e templates.
- 13 — FastAPI: endpoints assíncronos e documentação automática.

## ▶️ Como executar (rápido)

1. Clone o repositório:

```powershell
git clone https://github.com/digitalinnovationone/trilha-python-dio.git
cd trilha-python-dio
```

2. Crie e ative um ambiente virtual:

Windows (PowerShell):
```powershell
python -m venv venv
venv\Scripts\Activate.ps1
```

Windows (cmd):
```cmd
python -m venv venv
venv\Scripts\activate
```

Linux / macOS:
```bash
python3 -m venv venv
source venv/bin/activate
```

3. (Opcional) Instale dependências do módulo, se houver:

```powershell
pip install -r requirements.txt
```

4. Navegue até o módulo desejado e execute os scripts conforme instruções dentro da pasta.
